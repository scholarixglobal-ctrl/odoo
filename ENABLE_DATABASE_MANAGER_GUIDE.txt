🔧 OPTION 4: CHECK REVERSE PROXY (NGINX/APACHE)
------------------------------------------------

Sometimes database manager is blocked by web server, not Odoo.

Check NGINX configuration:
sudo nano /etc/nginx/sites-available/odoo.scholarixglobal.com

Look for location block that blocks /web/database:
location ~* /web/database {
    deny all;  # <-- This blocks database manager
}

To enable, either:
  • Remove the deny block entirely
  • Or change to: allow all;

Then reload NGINX:
sudo nginx -t
sudo systemctl reload nginx

🌍 OPTIONAL: EXTERNAL ACCESS (From Internet)
──────────────────────────────────────────────────────────────────────────────

If you want to access Odoo from outside your LAN, there are two options:

OPTION 1: Port Forwarding (Requires Router Access)
─────────────────────────────────────────────────

1. Open router admin panel (usually 192.168.0.1)
2. Log in with router credentials
3. Find "Port Forwarding" settings
4. Create rule:
   - External Port: 8069 (or any unused port like 9000)
   - Internal IP: 192.168.0.157
   - Internal Port: 8069
   - Protocol: TCP
5. Save and restart router
6. Note your PUBLIC IP from https://whatismyipaddress.com
7. Access from anywhere: http://<PUBLIC_IP>:8069

RISKS:
  ⚠️ Exposes Odoo to internet
  ⚠️ Requires strong password
  ⚠️ Firewall must allow inbound

OPTION 2: Cloudflare Tunnel (More Secure)
──────────────────────────────────────────

Requires setup with Cloudflare account (recommended for production).
Contact: [Admin/DevOps] for deployment.


📋 TROUBLESHOOTING:
──────────────────────────────────────────────────────────────────────────────

"Connection refused" or "No response":
  → Check if on same Wi-Fi: ipconfig (should see 192.168.0.x)
  → Restart browser
  → Wait 60 seconds for Odoo to initialize
  → Restart Docker: docker compose restart

"Cannot find server":
  → IP might have changed (DHCP lease expired)
  → Run: ipconfig
  → Look for new IPv4 address in Wi-Fi adapter section
  → Update bookmarks

"Login failed":
  → Confirm credentials are correct
  → Check Caps Lock
  → Try admin account first

Still having issues?
  → Check Docker status: docker ps
  → View logs: docker logs odoo19-odoo-1 --tail 50
  → Restart services: docker compose restart

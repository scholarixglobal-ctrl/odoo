SOLUTION 1: TEST NETWORK CONNECTION (DO THIS FIRST)
================================================================================

Before SSH, verify network connectivity:

Option A - Using PowerShell (Admin):
  1. Open PowerShell as Administrator
  2. Run: Test-NetConnection -ComputerName odoo.scholarixglobal.com -Port 22
  3. If it says "TcpTestSucceeded : True" → Network is OK
  4. If it says "False" → Network/Firewall is blocking

Option B - Using Command Prompt (Admin):
  1. Open CMD as Administrator
  2. Run: telnet odoo.scholarixglobal.com 22
  3. If connected → Good
  4. If fails → Network is blocking

Option C - Using SSH with Verbose:
  1. Open PowerShell or CMD
  2. Run: ssh -vvv USER@odoo.scholarixglobal.com
  3. Watch the output to see where it fails

SOLUTION 2: CHECK SSH KEY PERMISSIONS
================================================================================

SSH keys need correct permissions. Run these commands:

PowerShell (Admin):
  icacls C:\Users\USER\.ssh\id_rsa /inheritance:r /grant:r "%USERNAME%:F"
  icacls C:\Users\USER\.ssh /inheritance:r /grant:r "%USERNAME%:F"

Or manually:
  1. Right-click C:\Users\USER\.ssh\id_rsa
  2. Properties → Security
  3. Make sure only YOUR user has permissions
  4. Remove all other users/groups

📞 TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────

"Voice Assistant menu not appearing?"
  → Click: Settings → Apps (search bar)
  → Search "voice" to find the module
  → If not found, refresh page or check if it was installed

"Transcribe button doesn't work?"
  → Check: API key is valid
  → Check: Audio file is in supported format
  → Check: Browser console for error (F12)

"API Key error?"
  → Go to: Settings → Voice Assistant Configuration
  → Paste new API key from https://platform.openai.com/api-keys
  → Click: Save

"Create Lead button fails?"
  → Ensure CRM module is installed (should be)
  → Check: User has permission to create leads
  → Check: Default team/stage exist (Sales team, New stage)
